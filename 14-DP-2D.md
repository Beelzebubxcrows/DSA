# 14 · Dynamic Programming: 2D

> **Prereqs:** 13 · **Time:** 5–6 days

## When to use

- **Two sequences** to compare (LCS, edit distance, interleaving).
- A **grid** of paths.
- One sequence plus an extra dimension such as remaining capacity, a state machine (holding a stock or not), or an interval `[i, j]`.

## Common 2D shapes

| Shape | State | Transition idea |
|-------|-------|-----------------|
| Grid paths | `dp[r][c]` | from the cell above or to the left |
| Two strings | `dp[i][j]` = answer for `a[:i]`, `b[:j]` | if the characters match, take the diagonal; otherwise combine the neighbours |
| Knapsack | `dp[i][cap]` | take item i or skip it |
| State machine | `dp[i][state]` | transitions between states such as hold, sold and cooldown |
| Interval | `dp[l][r]` | try every split point k in `(l, r)`, iterating by length |

## Templates

```python
# LCS
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1] + 1
        else:
            dp[i][j] = max(dp[i-1][j], dp[i][j-1])

# Edit distance
dp[i][0] = i; dp[0][j] = j
dp[i][j] = dp[i-1][j-1] if a[i-1] == b[j-1] else \
           1 + min(dp[i-1][j],     # delete
                   dp[i][j-1],     # insert
                   dp[i-1][j-1])   # replace

# Interval DP (iterate by length)
for length in range(2, n + 1):
    for l in range(n - length + 1):
        r = l + length - 1
        for k in range(l, r):
            dp[l][r] = best(dp[l][r], dp[l][k] + dp[k+1][r] + cost(l, k, r))
```

## Pitfalls

- Index shifting: when `dp` has size `n+1`, `dp[i]` corresponds to `a[i-1]`.
- Loop order: interval DP must iterate **by length**, not by `l`.
- Counting problems (Coin Change II): putting the coin loop **outside** counts combinations, while putting it inside counts permutations.
- Space optimisation: if each row depends only on the previous row, keep 1D arrays for the previous and current rows.
